# Закрытые модули JUnit

Ровно десять неизменённых официальных JAR для приватного запуска JUnit 5.14.1 / Platform 1.14.1. Состав, точные URL, SHA-1 официальных receipts, вычисленные SHA256 и фактические module descriptors перечислены в `provenance.json`; лицензии из архивов сохранены в `licenses/`.

Публичная компиляция и Gradle продолжают использовать прежний `../junit-platform-console-standalone-1.14.1.jar`. Приватный запуск получает только этот конечный набор и прежний `../json-simple-1.1.1.jar` на module path, без standalone на classpath. Копии создаются отдельно для каждого задания и проверяются по закреплённым SHA256 при копировании.

Поставка selected10 и замкнутый runtime graph не означают полную effective Maven parent/BOM resolution и сами по себе не подтверждают приёмку защиты, образа или курса. Новые исходники проходят независимую рецензию и отдельные фактические проверки.
