# Неприменённые предложения для продолжения Platform

Эти файлы сохраняют диагностические материалы ночной сессии. Они не подключены к продуктовой сборке.

- `observer-closure-candidate01/fix.diff` — независимо проверенное по исходникам, неприменённое исправление диагностической защиты.
- `normal-capture04/capture-one-normal-vector.source-only.py.txt` — полный текст инструмента наблюдения SOURCE04; расширение `.txt` сохраняет его отдельно от исполняемого состава. Его исходная проверка завершена, запуск не выполнялся.
- `manifest.json` — размеры, SHA256 и исходные локальные пути сохранённых материалов.

Результат рецензии исходников не означает успешного выполнения. Перед запуском нужны отдельное поручение, проверка границ и независимая приёмка.
