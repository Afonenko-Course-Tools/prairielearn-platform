# Простой запуск Java и JUnit

Принято владельцем 7 ноября 2026 года. Этот документ заменяет требования
к доказательной обвязке Java/JUnit из незавершённой ночной итерации.

## Граница реализации

Gradle собирает проект, штатный JUnit выполняет тесты. Небольшой адаптер
публичных Launcher/Listener API переводит результат для PrairieLearn.
Публичные исключения OpenTest4J дают сообщение и expected/actual, когда эти
данные доступны. Учебные случаи, обязательный API и правила баллов сохраняются.

Достаточная диагностика:

- компиляция: файл, строка и сообщение;
- обязательный API: конкретное несовпадение;
- тест: имя отдельного случая и его статус;
- assertion: сообщение автора и доступные expected/actual;
- исключение: тип, сообщение и относящиеся к решению строки стека;
- ограниченный stdout/stderr; полный стек в частном отчёте преподавателя;
- таймаут, прерывание или сбой инструмента без выдуманной оценки.

Непубличные классы JUnit, скрытые классы, synthetic-методы, bytecode index,
инструментирование assertions, снимки произвольных объектов, собственные
полномочия событий и подписи отчётов не используются. Адаптер не доказывает
неподделываемость каждого события внутри JVM со студенческим кодом.

Изоляция процесса, ограничения ресурсов, защита путей и приватных файлов,
проверка обязательных входных полей и штатная аутентификация сохраняются.
Git и OCI используются обычным способом; собственные квитанции допуска,
многократные inventories и доказательства неизменности деревьев не нужны.

## План текущей сессии

1. Сохранить прежние ветки; заменить неудачную Java/JUnit-цепочку.
2. Согласовать непосредственных потребителей и зависимости CI.
3. Проверить обычные исходы, затем окончательные сценарии курса партиями.
4. Подготовить Java и System Practice к отдельной установке на прежней VM.
5. Перенести только пользователей и права с точными UID.
6. Принять новые сдачи и вход, затем переключить публикацию.

Прежние оценки признаны владельцем недостоверными. Перенос, пересчёт,
исправление оценок и признание старых зачётов запрещены до отдельного
указания владельца после развёртывания и проверки. Старая установка и данные
сохраняются; новая база не получает старых попыток и результатов.

Координатор назначает ограниченные задачи Sol, Terra или Luna; допускаются
подагенты и согласованный параллельный чат. Один владелец на изменяемый файл,
одна итоговая независимая техническая рецензия. Исторические процедуры
модельного допуска и доказательные пакеты не возобновляются.

Ориентир остатка аккаунта — около 2000 кредитов. Расход читается после
законченных блоков; при приближении к резерву сохраняются исходники,
результаты команд и точный следующий шаг.
