# Platform 2.5.1: полный состав ролей поставки

Штатная сборка поставки с Git Workspace отклоняла опубликованный receipt с четырьмя
образами: исходный images.lock.json не объявлял роль spGitWorkspace. Роль добавлена
с закреплённым базовым образом; действующий assembly consumer сохраняет закрытый
состав, source/version/digest и полный контроль входов.

Регрессия проверяет настоящий source-bound Context: полная поставка принимается,
отсутствующая роль и чужой digest отвергаются. Проверки не запускают контейнеры
и используют явно синтетические образы. Реальный выпуск требует независимой
рецензии, CI, новой публикации образов и проверки опубликованных файлов.

Исходники, теги, assets и OCI выпуска 2.5.0 сохраняются без изменения. Исправление
не объявляет готовыми курсы, перенос пользовательских данных или рабочий портал.
